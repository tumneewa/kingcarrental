# ระบบจัดการรถเช่า — คู่มือติดตั้งฉบับละเอียด

คู่มือนี้เขียนสำหรับคนที่ไม่มีพื้นฐานเขียนโปรแกรม ทำตามทีละขั้นได้เลยครับ
ใช้เวลารวมประมาณ 30–60 นาที และ**ไม่มีค่าใช้จ่าย**ในขั้นนี้ (ใช้แผนฟรีทั้งหมด)

---

## สิ่งที่ต้องมีก่อนเริ่ม
- อีเมล 1 ใบ (สำหรับสมัครบัญชี)
- โฟลเดอร์นี้ทั้งหมด (ไฟล์โค้ดที่ได้รับ)

---

## ขั้นที่ 1 — สร้างฐานข้อมูล (Supabase)

1. ไปที่ https://supabase.com กด **Start your project** แล้วสมัครด้วยอีเมลหรือ GitHub
2. กด **New project**
   - ตั้งชื่อโปรเจกต์ เช่น `rental-shop`
   - ตั้งรหัสผ่านฐานข้อมูล (เก็บไว้ดีๆ อาจไม่ต้องใช้อีกแต่ควรจำไว้)
   - เลือก Region ที่ใกล้ที่สุด เช่น Singapore
   - กด **Create new project** แล้วรอ 1-2 นาทีให้ระบบสร้างเสร็จ
3. เมื่อเข้าหน้าโปรเจกต์แล้ว ไปที่เมนูซ้าย **SQL Editor** → กด **New query**
4. เปิดไฟล์ `supabase/schema.sql` ที่ได้รับมา คัดลอกทั้งหมด แล้ววางในช่อง query
5. กด **Run** (มุมขวาล่าง) — ถ้าสำเร็จจะเห็นข้อความ "Success. No rows returned"
   - นี่คือขั้นตอนที่สร้างตารางรถ, ลูกค้า, การจอง และระบบสิทธิ์ทั้งหมด

## ขั้นที่ 2 — เก็บกุญแจเชื่อมต่อ (API Keys)

1. ไปที่เมนูซ้าย **Project Settings** (ไอคอนเฟือง) → **API**
2. คุณจะเห็น 2 ค่าที่ต้องใช้:
   - **Project URL** (ขึ้นต้นด้วย `https://...supabase.co`)
   - **anon public** key (สตริงยาวๆ ใต้หัวข้อ Project API keys)
3. เปิดไฟล์ `.env.local.example` ที่ได้รับมา คัดลอกทั้งไฟล์ แล้วสร้างไฟล์ใหม่ชื่อ `.env.local` (ไฟล์เดียวกันแต่ลบ `.example` ออก) วางค่าทั้งสองที่คัดลอกมาแทนที่

## ขั้นที่ 3 — สร้างบัญชีพนักงาน

1. ในหน้า Supabase ไปที่เมนูซ้าย **Authentication** → **Users**
2. กด **Add user** → **Create new user**
3. กรอกอีเมลและรหัสผ่านของพนักงานคนแรก (เช่นตัวคุณเอง) → ติ๊ก **Auto Confirm User** → กด **Create user**
4. ทำซ้ำสำหรับพนักงานคนอื่นๆ ในทีม (แต่ละคนมีอีเมล/รหัสผ่านของตัวเอง)
   - พนักงานแต่ละคนจะตั้งชื่อของตัวเองในระบบได้เองตอนล็อกอินครั้งแรก

## ขั้นที่ 4 — เอาเว็บขึ้นออนไลน์ (Vercel)

1. ไปที่ https://vercel.com กด **Sign Up** (สมัครด้วย GitHub จะง่ายที่สุด)
2. วิธีที่ง่ายที่สุดสำหรับคนไม่มีพื้นฐาน: อัปโหลดโฟลเดอร์นี้ขึ้น GitHub ก่อน
   - สมัคร https://github.com (ถ้ายังไม่มีบัญชี)
   - สร้าง repository ใหม่ (กด New → ตั้งชื่อ เช่น `rental-shop-app` → Create repository)
   - อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไป (ลากไฟล์วางในหน้าเว็บ GitHub ได้เลย ผ่านปุ่ม "uploading an existing file")
3. กลับไปที่ Vercel → กด **Add New Project** → เลือก repository ที่อัปโหลดไว้ → กด **Import**
4. ก่อนกด Deploy ให้เปิดส่วน **Environment Variables** แล้วเพิ่ม 2 ค่าเดียวกับที่อยู่ใน `.env.local`:
   - `NEXT_PUBLIC_SUPABASE_URL` = (Project URL จากขั้นที่ 2)
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY` = (anon public key จากขั้นที่ 2)
5. กด **Deploy** รอประมาณ 1-2 นาที
6. เสร็จแล้ว! Vercel จะให้ลิงก์เว็บมา เช่น `https://rental-shop-app.vercel.app` — นี่คือ**หน้าแรกสำหรับลูกค้า** ส่วนพนักงานเข้าใช้งานที่ `https://rental-shop-app.vercel.app/staff`

## ขั้นที่ 5 — ทดสอบใช้งาน

1. เปิดลิงก์หลัก (เช่น `https://rental-shop-app.vercel.app`) → จะเห็นหน้าแรกร้าน
2. ไปที่ `/staff` → ล็อกอินด้วยอีเมล/รหัสผ่านที่สร้างไว้ในขั้นที่ 3
2. ตั้งชื่อของคุณตอนเข้าใช้งานครั้งแรก
3. ลองเพิ่มรถคันแรก ลองจองดู — ข้อมูลจะถูกบันทึกจริงในฐานข้อมูล ใช้ร่วมกันได้ทุกคน

---

## ขั้นที่ 6 — เว็บไซต์หน้าแรกสำหรับลูกค้า (ใหม่)

ตอนนี้โครงสร้างเว็บเปลี่ยนเป็น 3 ส่วนแยกกันชัดเจน:

| หน้า | ใครเห็น | คืออะไร |
|---|---|---|
| `/` (หน้าแรก) | ทุกคน | เว็บไซต์แนะนำร้าน มีรูปรถ เกี่ยวกับเรา ที่ตั้ง/เบอร์โทร |
| `/book` | ทุกคน | หน้าจองรถ (ไม่ต้องล็อกอิน) |
| `/staff` | พนักงานที่ล็อกอินแล้วเท่านั้น | ระบบจัดการหลังร้าน |

**แก้ข้อความหน้าแรกให้เป็นร้านของคุณ:**
เปิดไฟล์ `app/page.jsx` ดูช่วงต้นไฟล์จะเห็นบล็อกนี้ แก้แค่ข้อความในเครื่องหมายคำพูดได้เลย ไม่ต้องแตะโค้ดส่วนอื่น:
```js
const SHOP_NAME = "ร้านเช่ารถของคุณ";
const SHOP_TAGLINE = "เช่ารถง่าย จองออนไลน์ได้ทันที ไม่ต้องโทรถาม";
const SHOP_ABOUT = "...";
const SHOP_ADDRESS = "...";
const SHOP_PHONE = "081-234-5678";
const SHOP_HOURS = "เปิดทุกวัน 08:00–20:00";
```
แก้ในเว็บ GitHub ได้เลย (กดไอคอนดินสอที่ไฟล์ → แก้ข้อความ → Commit) แล้ว Vercel จะ deploy เวอร์ชันใหม่ให้อัตโนมัติ

**เพิ่มโลโก้ร้าน / รูปพื้นหลัง hero:**
1. ไปที่ Supabase → เมนูซ้าย **Storage** → เลือก bucket ชื่อ `site-assets` (ถ้ายังไม่เห็น ให้รันไฟล์ `schema.sql` เวอร์ชันล่าสุดอีกครั้งก่อน)
2. กด **Upload file** แล้วเลือกรูปโลโก้/รูปพื้นหลังจากเครื่อง
3. คลิกที่ไฟล์ที่อัปโหลดแล้ว → กด **Copy URL** (หรือ Get public URL)
4. เปิดไฟล์ `app/page.jsx` แก้บรรทัดนี้ วางลิงก์ที่คัดลอกมา:
```js
const SHOP_LOGO_URL = "";        // วางลิงก์โลโก้ตรงนี้
const SHOP_HERO_IMAGE_URL = "";  // วางลิงก์รูปพื้นหลัง hero ตรงนี้
```
เว้นว่างไว้ได้ถ้ายังไม่มีรูป ระบบจะใช้ตราสัญลักษณ์ป้ายทะเบียนเริ่มต้นให้แทน

## ขั้นที่ 7 — เพิ่มรูปรถ (ใหม่)

หน้าแรกและหน้าจองจะโชว์รูปรถจริงของคุณ ถ้าอัปโหลดไว้ ทำได้ดังนี้:
1. รันไฟล์ `schema.sql` เวอร์ชันล่าสุดนี้อีกครั้งใน Supabase → SQL Editor (จะสร้างที่เก็บรูปให้อัตโนมัติ ส่วนที่มีอยู่แล้วจะไม่ถูกสร้างซ้ำ)
2. ไปที่หน้า `/staff` → รถทั้งหมด → เพิ่มรถ → จะมีช่อง "รูปรถ (ไม่บังคับ)" ให้เลือกไฟล์ภาพจากมือถือ/คอมได้เลย
3. รูปจะไปโชว์ทั้งในหน้าแรก หน้าจองของลูกค้า และหน้าจัดการของพนักงานทันที

## ขั้นที่ 8 — เปิดให้ลูกค้าจองรถเอง

หน้า **`/book`** ให้ลูกค้าจองรถได้เอง โดยไม่ต้องล็อกอิน ส่งลิงก์นี้ให้ลูกค้าได้เลย (แนบในเพจร้าน, LINE, Facebook)
หรือกดปุ่ม "จองรถเลย" / "จองคันนี้" จากหน้าแรกก็จะพาไปหน้านี้โดยเลือกรถให้อัตโนมัติ

**เมื่อลูกค้าจองผ่านหน้านี้ จะเกิดอะไรขึ้น:**
1. ลูกค้าเลือกรถ เลือกวันที่ (ระบบจะบล็อกวันที่ถูกจองไปแล้วให้อัตโนมัติ) กรอกชื่อ-เบอร์โทร แล้วส่งคำขอ
2. คำขอจะเข้าไประบบของพนักงานทันที ในสถานะ **"รอยืนยัน"** — จะโชว์เด่นในหน้า "ภาพรวม" และ "ประวัติการจอง"
3. พนักงานกด **ยืนยัน** หรือ **ปฏิเสธ** คำขอนั้น — ถ้ายืนยัน รถจะถูกจองจริง ถ้าปฏิเสธ วันที่นั้นจะว่างกลับมาให้จองใหม่ได้
4. ระหว่างที่ยังรอยืนยัน ระบบจะกันไม่ให้ลูกค้าคนอื่นจองวันที่ซ้อนกันซ้ำ

**หากคุณตั้งฐานข้อมูลไปแล้วก่อนหน้านี้** ให้ไปที่ Supabase → SQL Editor → New query แล้วรันไฟล์ `schema.sql` เวอร์ชันใหม่นี้อีกครั้งได้เลย ส่วนที่มีอยู่แล้วจะไม่ถูกสร้างซ้ำ ส่วนใหม่จะถูกเพิ่มเข้าไป

⚠️ **ข้อจำกัดของเวอร์ชันนี้:** ถ้าลูกค้าคนเดิมจองซ้ำด้วยเบอร์โทรเดิม ระบบจะรู้จำและใช้ข้อมูลลูกค้าเดิมให้ แต่ถ้าใช้เบอร์คนละเบอร์ (เช่น พิมพ์ผิด) จะสร้างเป็นลูกค้าใหม่แยกกัน พนักงานอาจต้องรวมข้อมูลลูกค้าเองเป็นครั้งคราว

## ขั้นที่ 9 — รับชำระเงินผ่านพร้อมเพย์ (ใหม่)

ระบบจะแสดงคิวอาร์โค้ดพร้อมเพย์ให้ลูกค้าสแกนจ่ายทันทีหลังส่งคำขอจอง โดยไม่ต้องขอบัญชีเกตเวย์รับเงินใดๆ (เหมาะกับร้านที่ยังไม่ได้จดบริษัท)

**วิธีเปิดใช้งาน:**
1. เปิดไฟล์ `lib/shopConfig.js` แก้บรรทัดนี้ ใส่เบอร์โทรที่ผูกพร้อมเพย์ไว้ (หรือเลขบัตรประชาชน 13 หลัก):
```js
export const SHOP_PROMPTPAY_ID = "0812345678";
export const SHOP_DEPOSIT_AMOUNT = 1000; // ยอดมัดจำที่ต้องโอนเพื่อยืนยันการจอง (บาท)
```
2. เว้น `SHOP_PROMPTPAY_ID` ว่างไว้ (`""`) ถ้ายังไม่อยากเปิดใช้ — ลูกค้าจะจองได้ตามปกติ แค่ไม่มีขั้นตอนจ่ายเงินโผล่ขึ้นมา

**การทำงาน (แบบไม่ต้องมีบัญชีเกตเวย์ พนักงานตรวจสอบเอง):**
1. ลูกค้าส่งคำขอจอง → ระบบโชว์คิวอาร์โค้ดพร้อมเพย์พร้อม**ยอดมัดจำ** (ไม่ใช่ยอดรวมค่าเช่าทั้งหมด — ส่วนที่เหลือมักเก็บตอนรับรถ) ให้สแกนจ่ายทันที
2. ลูกค้าโอนเงินผ่านแอปธนาคาร แล้ว**แนบรูปสลิปโอนเงิน** (ไม่บังคับแต่แนะนำ) จากนั้นกดปุ่ม **"แจ้งว่าชำระเงินแล้ว"**
3. พนักงานเช็คเงินเข้าจากแอปธนาคาร/SMS ของร้าน พร้อมกดดูรูปสลิปที่ลูกค้าแนบมาเทียบกัน แล้วไปที่หน้า "ภาพรวม" หรือ "ประวัติการจอง" กดปุ่ม **"ได้รับเงินแล้ว"** เพื่อยืนยัน (มีลิงก์ "ดูสลิป" ให้กดเปิดดูรูปได้เลย)

⚠️ **ข้อจำกัด:** ระบบนี้ไม่ได้เชื่อมกับธนาคารจริง จึงไม่สามารถยืนยันอัตโนมัติว่าเงินเข้าจริงหรือไม่ — พนักงานต้องเช็คเงินเข้าด้วยตัวเองเสมอก่อนกดยืนยัน ถ้าต้องการระบบยืนยันอัตโนมัติในอนาคต จะต้องจดทะเบียนบริษัทและสมัครบัญชีเกตเวย์ เช่น Omise/Opn Payments หรือ 2C2P เพิ่มเติม

## คำถามที่พบบ่อย
 (เช่น mycar-rental.com) ทำยังไง?**
ซื้อโดเมนจากผู้ให้บริการ (เช่น Namecheap, GoDaddy) แล้วไปตั้งค่าใน Vercel → Project → Settings → Domains ตามคำแนะนำในหน้านั้น

**ถ้าอยากเพิ่ม/ลบพนักงาน ทำยังไง?**
ไปที่ Supabase → Authentication → Users แล้วเพิ่ม/ลบได้เลย ไม่ต้อง deploy ใหม่

**ถ้าจะดูข้อมูลดิบ (เช่น export เป็น Excel) ทำยังไง?**
ไปที่ Supabase → Table Editor → เลือกตาราง → มีปุ่ม export เป็น CSV ให้

**เมื่อไหร่ที่ต้องเริ่มจ่ายเงิน?**
แผนฟรีของ Supabase และ Vercel เพียงพอสำหรับร้านเล็ก-กลางแทบทุกกรณี จะต้องอัปเกรดก็ต่อเมื่อฐานข้อมูลเกิน 500MB หรือมีการใช้งานหนักมากจริงๆ ถ้าเข้าใกล้ขีดจำกัด ทั้งสองระบบจะมีอีเมลแจ้งเตือนล่วงหน้า
